# shell-emulator_practice

Эмулятор командной оболочки UNIX-подобной ОС с виртуальной
файловой системой (VFS) в памяти. Python 3 + PyQt5.
Вариант №28.

## 1. Общее описание

Эмулятор предоставляет графический REPL: пользователь вводит
команды, эмулятор отвечает в стиле UNIX. Все операции
производятся над VFS, загруженной из CSV-файла. Двоичные данные
файлов хранятся в base64. Данные на диске не изменяются.

## 2. Функции и настройки

### Параметры командной строки

- `--vfs PATH`    — путь к CSV с VFS;
- `--script PATH` — путь к стартовому скрипту (опционально).

При запуске эмулятор печатает все заданные параметры.

### Команды

- `ls [PATH]`         — вывести содержимое каталога;
- `cd [PATH]`         — сменить текущий каталог;
- `tree [PATH]`       — рекурсивно вывести дерево;
- `uptime`            — время работы эмулятора в секундах;
- `chmod MODE PATH`   — изменить режим узла (в памяти);
- `exit`              — закрыть эмулятор.

### Стартовый скрипт

Выполняется построчно. Строки, начинающиеся с `#`, —
комментарии. Скрипт останавливается при первой ошибке.

## 3. Сборка и запуск тестов

Установка зависимостей:

    pip install PyQt5

Запуск:

    python main.py --vfs vfs_samples/deep.csv --script scripts/start_deep.txt

Интерактивно (без скрипта):

    python main.py --vfs vfs_samples/minimal.csv
